Časté otázky

Posílají se moje texty někam?

Web nemá vlastní server a nic neukládá. Texty se posílají přímo z vašeho prohlížeče na akademické API ÚFAL (LINDAT) ke zpracování. Anonymizér navíc nabízí lokální režim, kde text neopustí váš počítač.

Jaké jazyky umí překladač?

Překládá mezi češtinou, angličtinou, němčinou, francouzštinou, polštinou, ruštinou a ukrajinštinou. Pro češtinu a angličtinu používá CUBBITT, jeden z nejkvalitnějších dostupných překladačů.

Je to zdarma?

Ano, pro nekomerční použití. Nástroje stojí na otevřených projektech ÚFAL MFF UK: NameTag, UDPipe, Korektor a Charles Translator (CUBBITT).

Anonymizace je neoficiální komunitní projekt. Není provozován ani schválen ÚFAL MFF UK, využívá jejich veřejná API LINDAT (NameTag, UDPipe, Korektor, CUBBITT). Nahrazení značkami je pseudonymizace, výstup si vždy zkontrolujte.
